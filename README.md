# Նուռ — армянский с нуля

Тренажёр восточноармянского для русскоязычных: алфавит по группам,
уроки-фразы с озвучкой и интервальное повторение.

Работает полностью офлайн, без ключей и оплаты. Прогресс хранится
в `localStorage` браузера.

## Требования

- Node.js 18 или новее

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

## Сборка статики

```bash
npm run build      # результат в dist/
npm run preview    # локально посмотреть собранное
```

Содержимое `dist/` — обычные статические файлы, можно выложить на любой
хостинг (GitHub Pages, Netlify, Cloudflare Pages и т.п.).

## PWA — установка на устройство

Приложение — устанавливаемое PWA: манифест (`public/manifest.webmanifest`),
service worker (`public/sw.js`, офлайн-кэш) и иконки-гранаты
(`public/icon-*.png`, генерируются `node scripts/make-icons.mjs`).

После установки открывается в отдельном окне **без адресной строки и кнопок
браузера** (`display: standalone`).

Условие: сайт должен открываться по **HTTPS** (или `http://localhost` для
проверки). С `file://` и по локальной сети без сертификата установка
не сработает.

- **Десктоп Chrome/Edge:** значок «Установить» в адресной строке →
  ярлык на рабочем столе.
- **Android Chrome:** меню → «Установить приложение».
- **iOS Safari:** «Поделиться» → «На экран Домой».

### Публикация на GitHub Pages

1. Залить проект в репозиторий на GitHub, ветка `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Пуш в `main` — workflow `.github/workflows/deploy.yml` сам собирает и
   публикует. Адрес вида `https://<user>.github.io/<repo>/`.

`base: "./"` в `vite.config.js` уже настроен на публикацию в подпапке.

Без GitHub: перетащить папку `dist/` в Netlify Drop или Cloudflare Pages —
получите HTTPS-адрес, установка работает так же.

## Файлы

| Файл | Назначение |
|---|---|
| `nur-armenian.jsx` | всё приложение (компоненты + чистая логика в блоке `LOGIC-START…LOGIC-END`) |
| `src/main.jsx` | точка входа, монтирует `<App />` |
| `vite.config.js` | конфиг сборщика; `base: "./"` + номер сборки `__BUILD__` (дата и время МСК) |
| `public/` | манифест, service worker, иконки — копируются в `dist/` как есть |
| `scripts/make-icons.mjs` | генератор иконок-гранатов (без зависимостей) |
| `.github/workflows/deploy.yml` | автосборка и публикация на GitHub Pages |

Номер сборки виден в шапке приложения справа («сборка ДД.ММ.ГГГГ, ЧЧ:ММ») и
обновляется при каждом `npm run dev` и `npm run build`.
